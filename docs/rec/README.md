# rec/ — video explicativo

Este directorio contiene el video asciinema de **ESP32-CAM Blink** y el reproductor
que se usa en la página del proyecto.

- `esp32cam-blink.cast`: grabación original (asciicast v2).
- `esp32cam-blink.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:44. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
